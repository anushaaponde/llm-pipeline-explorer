# Groq LLM Playground (Dark Green Editorial Edition)

An interactive, single-file playground for exploring LLM parameters, prompt techniques, tokens, and reasoning speeds with the Groq API.

## Features

- **Dark Green & Botanical Editorial Theme**: Crafted with deep midnight pine (`#07120b`), rich forest panels (`#0d1e15`), and vibrant emerald accents (`#10b981`).
- **Human-like Typography**: Paired with *Newsreader* (an editorial serif) for headings and verdicts, *Plus Jakarta Sans* for readable UI, and *JetBrains Mono* for code and metrics.
- **Interactive Controls**: Temperature, max tokens, custom stop sequences, web search, and reasoning mode.
- **Real-Time Prompt Analysis**: Rule-based detection for Zero-Shot, One-Shot, Few-Shot exemplars, Chain-of-Thought, Role Prompting, and constraints.
- **Live Performance & Quota Diagnostics**: Time-to-first-token (TTFT), tokens/sec (TPS), token breakdown, and per-minute rate-limit counters.
- **Request Snippet Generator**: Export current parameters directly as cURL or Python (`openai` SDK).
